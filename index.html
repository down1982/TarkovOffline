  2. 进入左侧「Google Auth Platform / OAuth 同意屏幕」→ 选择 External（外部），在「测试用户」中添加你自己的 Gmail 邮箱（测试模式下无需 Google 审核，最多支持 100 个测试账号永久免费使用）。

  4. 在 「已获授权的 JavaScript 来源 (Authorized JavaScript origins)」 中添加当前访问来源：http://localhost:8080 （如部署到 GitHub/Cloudflare Pages 也一并填入对应域名）。
  5. 将生成的 Client ID（以 .apps.googleusercontent.com 结尾）粘贴到上方输入框保存即可授权同步。
